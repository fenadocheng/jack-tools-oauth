隱私權政策

最後更新：2026-10-14

適用對象

「Jack 個人工具」是開發者 Jack Cheng 自用的個人自動化工具，唯一使用者為開發者本人。

存取的資料

經使用者授權後，本工具透過 Google Calendar API 讀取與建立使用者本人的行事曆行程。

資料使用與保存

  • 資料只用於在使用者本人的個人助理中查詢與新增行程。
  • 授權憑證只保存在使用者本人的主機上，不上傳到任何第三方伺服器。
  • 不出售、不分享、不轉移任何資料給第三方，也不用於廣告。

本工具使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括「有限使用」規定。

撤銷授權

可隨時到 Google 帳戶的第三方存取權頁面撤銷授權。
